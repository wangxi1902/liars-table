# 身份规则与可选策略

这一阶段只解决一个问题：Prompt中哪些内容属于不可违反的游戏事实，哪些只是AI可以
选择或拒绝的战术思路。

## 1. 为什么必须拆开

旧版预言家说明包含：

```text
验到狼人必须立刻公开身份
不公开身份就毫无价值
```

但游戏规则只规定预言家能查验阵营，并没有规定查验后必须什么时候公开。立即跳身份、
隐藏身份和只做暗示是不同策略。把某一种策略写成“必须”，会让所有预言家行为一致，
也无法比较不同选择的效果。

## 2. 当前代码结构

`role_guidance.py`中有两个独立字典：

```python
ROLE_RULES: dict[Role, tuple[str, ...]]
OPTIONAL_STRATEGY_IDEAS: dict[Role, tuple[str, ...]]
```

`ROLE_RULES`只包含：

- 阵营和胜利目标相关事实；
- 角色能看到什么信息；
- 角色拥有哪些技能；
- 技能和合法目标受到什么约束。

`OPTIONAL_STRATEGY_IDEAS`包含可以考虑的行动方向。Prompt明确告诉模型：这些内容不是
指令，可以选择、组合、全部拒绝，也可以只根据证据进行普通决策。

## 3. Python基础：为什么用字典和元组

字典把角色映射到对应说明：

```python
ROLE_RULES[Role.SEER]
```

不需要写五组`if/elif`。每个角色的说明使用元组，因为配置创建后不需要在运行中增删，
元组能表达“这是一组稳定配置”。

## 4. 私有信息不等于强制行动

旧Prompt写“私有信息必须用起来”，这也会间接强迫预言家和女巫公开身份。现在改为：

```text
只有你知道的信息（是否以及如何使用，由你结合收益和风险决定）
```

AI仍会收到真实私有信息，但可以选择公开、暗示、暂时保留或用于内部判断。信息可见性
没有变化，只改变了Prompt对行动的强迫程度。

## 5. 当前还没有实现什么

“可选策略空间”只是候选想法，不等于Agent已经拥有持久策略。当前还没有：

- `StrategyPlan`对象；
- 策略开始、更新、放弃和过期状态；
- 自我承诺记忆；
- 故意欺骗与无意矛盾的区分。

这些要等个体记忆和自我发言压缩完成后再引入，否则策略没有可靠的历史状态可以依赖。

## 6. 学习检查点

**问题1：预言家能查验身份属于规则还是策略？**

参考答案：属于规则，因为这是角色固定能力。查验后立即公开还是暂时隐藏属于策略。

**问题2：为什么策略候选必须允许全部拒绝？**

参考答案：很多普通决策不需要长期战术。强迫每次选择策略会让行为虚假复杂，并让相同
角色机械执行同一套路。

**问题3：为什么私有信息不能写成“必须公开使用”？**

参考答案：私有信息可以用于内部判断，不代表必须在公开发言中暴露。公开时机会影响
收益和生存风险，是Agent需要权衡的策略问题。

**问题4：这次拆分是否改变了游戏规则引擎？**

参考答案：没有。规则引擎中的技能、阶段和合法性校验完全不变，本次只修改了模型看到
的指导文本和对应测试。

可选练习：为预言家分别写一条固定规则和三条可选策略，检查固定规则中是否混入了
“应该何时公开身份”之类的软性战术。
